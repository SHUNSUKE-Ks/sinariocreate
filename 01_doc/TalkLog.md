# 📘 会話ログ（TalkLog）メモ帳 仕様書（Markdown）

> 目的：**ゲームのログ形式のメモ帳**を、**コード不要**で再現できるようにするためのレイアウト & 機能仕様。対象：`src/TalkLog/`（Component と Hook をこのフォルダ内に集約）

---

## 1. 画面レイアウト（再現用）

```
┌──────────────────────────────────────────────────────────┐
│ タイトルバー                                             │
│  会話ログ｜（メイン / サブ）＋ シナリオフロー名          │   [× 削除]  ← 右隅
├──────────────────────────────────────────────────────────┤
│ TalkList（縦スクロール）                                 │
│  ┌─ 行（TalkItem） ────────────────────────────────────┐ │
│  │ [Icon]  名前（小見出し）                              │ │
│  │         セリフテキスト（吹き出し/カード）             │ │
│  │                                              [▶︎]     │ │ ← 右隅：音声再生（ワンショット）
│  └───────────────────────────────────────────────────┘ │
│  … 以降、最新順に追加                                     │
└──────────────────────────────────────────────────────────┘
```

- 基本配色：**暗背景 × 白系の吹き出し**（視認性優先）
- 行間：1.0〜1.25em、角丸：8〜12px（可変）
- スクロール：**下端自動追従（新規行追加時）**／ユーザーが上スクロール中は固定
- 余白：左右 16px、上下 12px（モバイルは左右 12px）
- 最小タップ領域：**44px**（音声ボタン・削除ボタン）

## 3. データ定義（JSON 形：コード実装不要）

### 3.1 ヘッダー情報

```jsonc
{
  "title": "会話ログ",
  "flow": {
    "type": "メイン", // または "サブ"
    "nextQuest": "タレブ病院の医者に会う"
  }
}
```

### 3.2 TalkList の 1 行（TalkItem）

```jsonc
{
  "id": 1101,
  "icon": "chara_leon.png", // キャラクターアイコンの識別子
  "name": "レムナント",
  "text": "ははっ。鉱山の魔石という…",
  "tags": ["sfx_voice_line"], // 任意：BGM/SE/演出などの抽象タグ
  "voice": "voice_1101.mp3" // 任意：存在する場合のみ再生ボタンを表示
}
```

> **整列規則**：既定＝**追加順**。`createdAt` があれば昇順。 **改行**：テキストは `\n` をそのまま改行として表示。

## 4. コンポーネント一覧（Props 一覧）

> 記法：`<Component (prop)/>`＝**変更できるプロパティ** 一言説明：**役割** / **主引数** / **CSS の意味**（超要約）

### 4.1 `<TitleBar (title, flowType, nextQuest, onClear)/>`

- 役割：画面上部タイトル帯
- 主引数：`title`（文字列）, `flowType`（"メイン" | "サブ"）, `nextQuest`（文字列）, `onClear`（削除押下時コールバック）
- CSS：横並び・右寄せボタン・区切り線

### 4.2 `<TalkList (items, onPlay)/>`

- 役割：ログの縦一覧
- 主引数：`items`（TalkItem 配列）, `onPlay(id)`（音声再生リクエスト）
- CSS：縦スクロール・パディング・リスト間隔

### 4.3 `<TalkItem (icon, name, text, voice, onPlay)/>`

- 役割：ログ 1 行（アイコン＋名前＋吹き出し＋右隅音声）
- 主引数：`icon`（URL/ID）, `name`（文字列）, `text`（文字列）, `voice`（URL/ID | null）, `onPlay()`
- CSS：グリッド/フレックスで**左：アイコン｜中央：本文｜右：音ボタン**

### 4.4 `<Avatar (src, alt, size)/>`

- 役割：丸いアイコン
- 主引数：`src`, `alt`, `size`（px）
- CSS：円形・枠線・影（任意）

### 4.5 `<Bubble (children, variant)/>`

- 役割：吹き出し枠
- 主引数：`children`（本文）, `variant`（"default" | "system" など）
- CSS：角丸・背景・内側余白

### 4.6 `<AudioButton (disabled, onClick, ariaLabel)/>`

- 役割：右隅の再生ボタン（ワンショット）
- 主引数：`disabled`（再生不可時）, `onClick`, `ariaLabel`
- CSS：最小 44px・フォーカスリング

### 4.7 `<DeleteButton (onConfirm)/>`

- 役割：ヘッダー右上の全削除
- 主引数：`onConfirm`（確認ダイアログ後に実行）
- CSS：アイコンボタン・危険色

## 5. Hook 一覧（API だけ記載／役割は一言）

- `useTalkLog(initialItems)`：**配列管理**（追加・削除・全消去・最新取得）
- `useAudioPlayer()`：**音声制御**（一曲のみ同時再生・再生中の排他）
- `useAutoScroll(dep)`：**自動スクロール**（新規追加時のみ最下部へ）

---

## 6. 機能要件（実装ルール）

1. **タイトル表示**：`会話ログ｜（メイン/サブ）＋ 次のクエスト名`
2. **削除ボタン**：右上 `[×]` → 確認ダイアログ → 承認で **全件消去**
3. **TalkList**：

   - アイコン（左）→ **名前**（小見出し）→ **テキスト**（吹き出し）
   - 右端に **音声再生ボタン**（`voice` がある行のみ表示）

4. **音声再生（ワンショット）**：

   - 同時再生不可（再生中に他を押すと前を停止）
   - 1 行は **1 ファイル**、押下で頭から再生

5. **スクロール挙動**：

   - 新規行追加時：**最下端へ自動追従**
   - ユーザーが上方向にスクロール中は追従を停止

6. **リスト更新**：

   - `items` が変化したら DOM を差分更新
   - 重複 `id` は無視（安全策）

7. **アクセシビリティ**：

   - ボタンに `aria-label`、キーボード操作可、フォーカス可視
   - 名前は見出しロール扱い（スクリーンリーダーの区切り）

8. **パフォーマンス**：

   - 長文テキストは**折返し**・オーバーフロー時の末尾省略（任意）
   - 画像は **32〜64px** 推奨・遅延読み込み可

9. **PWA/モバイル**：

   - 44px 以上のタップ領域、横幅 360px〜対応、音声はユーザー操作で解禁

## 9. 入力データテンプレ（md 用）

```yaml
# header
title: 会話ログ
flow:
  type: メイン
  nextQuest: タレブ病院の医者に会う

# list
items:
  - id: 2001
    icon: chara_leon.png
    name: レムナント
    text: "ははっ。鉱山の魔石という…"
    voice: voice_2001.mp3
  - id: 2002
    icon: chara_ratel.png
    name: ラテル
    text: "魔石…ですか？"
```

> この YAML/JSON を読み込めば、**同じ見た目と挙動**で再現可能。

---

## 10. 想定イベント（I/O）

- 入力：`items[]`（新規メッセージの追加）
- 出力：

  - `onPlay(id)`：音声再生要求
  - `onClear()`：全削除確定通知

---

## 11. エッジケース

- `voice` 無し：音ボタン**非表示**
- `text` 空：行を**スキップ** or 「…」表示（選択可）
- 長文：**自動折返し**、最大高さ超過時は内部スクロール
