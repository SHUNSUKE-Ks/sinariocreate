# MemoKeymap 機能仕様

## 📝 name（クリック）

- **機能**：クリックでキャラクターを選択。
- **注意**：`0` を選ぶと **none（ナレーション・地の文）** として扱います。　この場合、キャラクターアイコンは「**丸いアイコンの空白**」が表示されます。

---

## 🧑‍🎨 characterIcon（クリック）

- **機能**：クリックで**表情差分**を選択。
- **動作**：対応するキャラクター名・表情に基づいて画像が切り替わります。

---

## 💡 表示仕様

- **キャラクター名**： `キャラクター図鑑` に登録されているキャラクターのネームと一致。

- **表情差分**：

  ```js
  if (表情差分の画像が存在しない場合) {
      テキスト（キャラクター名と表情名）を代わりに表示する
  }
  ```

---

## ⚙️ ステート仕様

### default（通常時）

---

### textBox\_入力中（テキスト入力モード）

- `Alt + 数字キー` 　 → キャラクターの `name（キャラクター名）` を即座に変更

- `Enter` 　 → 通常のテキスト改行

- `Ctrl + Enter` 　 → 同じキャラクターのテキストボックスを **直下に 1 つ追加**
